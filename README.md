# STAVPAS™ | Pasporty skutečného stavu staveb

Moderní webová prezentace pro službu **Stavpas** – pasportizace a laserové zaměření skutečného stavu staveb (rodinné domy, chaty, chalupy, bytové domy, garáže a drobné stavby) dle stavebního zákona č. 283/2021 Sb.

## 🚀 Živý web na GitHub Pages
Po aktivaci GitHub Pages běží web přímo v prohlížeči (100% statický web bez nutnosti backendu).

## 📁 Struktura projektu
- `index.html` – Hlavní jednostránkový web
- `css/styles.css` – Styly a přizpůsobení rozhraní
- `js/calculator.js` – Online cenový konfigurátor a výpočet dle sazebníku Stavpas
- `js/app.js` – Interakce, mobilní menu, FAQ akordeon a formuláře
